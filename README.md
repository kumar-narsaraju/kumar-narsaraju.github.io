# Kumar Narsaraju | Portfolio Website

Personal portfolio of **Kumar Narsaraju**, Systems Engineer working with data center and GPU server infrastructure.

**Live site:** https://kumar-narsaraju.github.io

## About This Site

A dark, server-themed portfolio that works on computers, tablets and phones. It shows my work with large-scale GPU infrastructure, including 513 ASUS H100 servers and 500+ NVIDIA switches, and my skills in Linux, RAID, BMC and server troubleshooting.

## Features

- Interactive 3D model of the ASUS ESC N8-E11 7U HGX H100 server (drag to rotate, explode the parts, isolate each component)
- 2D architecture diagrams of a GPU cluster and of a single GPU node
- Experience, skills and certifications sections
- Resume available to view and download
- Links to LinkedIn, GitHub and Behance (Naukri can be added later)

## Project Structure

| File | Purpose |
|------|---------|
| `index.html` | The whole website (HTML, CSS and JavaScript) |
| `resume.pdf` | Latest resume, used by the View and Download buttons |
| `README.md` | This file |

## Built With

HTML, CSS, JavaScript and [Three.js](https://threejs.org/) for the 3D model. Hosted free on GitHub Pages.

## How To Update

- **Resume:** upload a new PDF named exactly `resume.pdf` to replace the old one.
- **Links, skills, certifications:** edit the `SITE` block near the bottom of `index.html`.
